04 / How I build

Small loop. Better result.

The workflow I naturally follow when building a website or experiment.

abdullah@portfolio:~
$ define "the idea"
$ design --responsive --interactive
$ build ./experience
$ test --mobile --desktop
$ ship ./github-pages
$ repeat
Design principle

Make the interface memorable —
without making it confusing.

The goal is not maximum animation. It is useful motion, clear hierarchy, fast navigation and a visual identity that people remember.
