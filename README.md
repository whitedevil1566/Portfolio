# Abdullah Afsar — Advanced Portfolio

A futuristic, responsive single-page developer portfolio for GitHub Pages.

## Files
- `index.html` — main portfolio
- `ar.html` — live camera holographic portfolio experience
- `CV.pdf` — CV
- `CNAME` — custom domain file if used

## Publish
Upload/replace the files in your GitHub Pages repository. Open `index.html` through HTTPS.

## Keyboard shortcut
Press **Ctrl+K** (Windows/Linux) or **Cmd+K** (Mac) for the command palette.
